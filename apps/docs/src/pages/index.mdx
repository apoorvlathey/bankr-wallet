# Your WalletChan, fully explained

WalletChan is an Ethereum and EVM browser wallet for connecting to dapps,
reviewing requests clearly, and managing assets across several custody and
signing models. It supports local accounts, Ledger, Safe multisig, view-only
addresses, optional Bankr remote signing, transaction simulation, swaps,
bridges, ETH shielding, and smart-account features.

Choose a task, search for an exact setting, or open the
[Feature atlas](/overview/feature-atlas) to see the whole product.

## Documentation built for people and AI agents

Press **⌘K** or **Ctrl+K** anywhere to search. For agents, every page is
available as Markdown by adding `.md` to its URL, and the site publishes
`/llms.txt`, `/llms-full.txt`, and a documentation MCP endpoint.

## New to self-custody?

Read [Passwords, unlock, and authorization](/security/passwords) and
[Backups and secret recovery](/security/backups) before moving meaningful
funds. WalletChan cannot recover a private key or seed phrase that you lose.

:::warning
Never share a private key, seed phrase, Shield recovery phrase, password, or
Ledger approval with anyone. WalletChan support will never ask for them.
:::

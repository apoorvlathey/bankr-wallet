# Install WalletChan

WalletChan is available for Chromium-based browsers and Firefox.

## Chrome and Chromium browsers

1. Open the [WalletChan Chrome Web Store
   listing](https://chromewebstore.google.com/detail/walletchan/kofbkhbkfhiollbhjkbebajngppmpbgc).
2. Select **Add to Chrome** and approve the browser prompt.
3. Open the Extensions menu and pin WalletChan for quick access.
4. Open WalletChan and complete
   [Create or import a wallet](/getting-started/create-or-import).

Chrome Web Store extensions also work in browsers that support Chromium
extensions, though browser-specific side-panel and popup behavior can differ.

## Firefox

Install from the [Firefox Add-ons
listing](https://addons.mozilla.org/en-US/firefox/addon/walletchan/). Firefox
supports the core wallet, dapp, account, and signing experience. Features that
depend on Chrome-only APIs, such as the standalone WalletChan Browser and
Ledger WebHID transport, may be unavailable.

## Confirm you installed the real extension

Use the store links above or links from
[walletchan.com](https://walletchan.com). Do not install an extension from a
file or an unofficial listing sent through direct messages.

## Updates

Store-installed builds update through your browser. After an update, the
wallet may run maintenance or migration work when it starts. Your existing
accounts should remain in place; if the UI looks stale, close and reopen the
extension before troubleshooting.
